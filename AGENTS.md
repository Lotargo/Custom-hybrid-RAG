# Инструкции для AI Агентов (Jules)

Этот проект активно использует аппаратные SIMD инструкции для ускорения (AVX2, AVX-512, NEON и др.).
Хост-процессор песочницы, в которой вы (AI Агент) работаете, может не поддерживать новые наборы инструкций (например, AVX-512), из-за чего тесты и бенчмарки могут "скипаться", а реальная проверка кода будет невозможна.

**Для полноценного тестирования AVX-512 (или других новых архитектур) вам необходимо установить Intel Software Development Emulator (Intel SDE).**

## Инструкция по установке Intel SDE в песочнице
Выполните следующие команды в bash для загрузки и распаковки актуального SDE:
```bash
mkdir -p /tmp/sde && cd /tmp/sde
wget -qO sde.tar.xz https://downloadmirror.intel.com/813591/sde-external-9.33.0-2024-01-07-lin.tar.xz
tar -xf sde.tar.xz --strip-components=1
```

## Как запускать тесты через эмулятор
После сборки проекта (`cmake .. && ninja`) запускайте скомпилированные бинарники, оборачивая их в `sde64` с флагом `-skx` (Skylake-X профиль) или `-future` для симуляции поддержки:
```bash
# Запуск юнит-тестов (AVX-512 тесты перестанут скипаться и будут реально выполнены)
/tmp/sde/sde64 -skx -- ./build/tests/rag_engine_tests

# Запуск бенчмарков (время в бенчмарках будет нерепрезентативным, но это докажет отсутствие падений)
/tmp/sde/sde64 -skx -- ./build/benchmarks/rag_engine_benchmarks
```

**Важное правило:** Никогда не предполагайте, что ваш AVX-512 код работает только потому, что он компилируется! Обязательно тестируйте его в Intel SDE, чтобы гарантировать отсутствие ошибок сегментации или некорректной математики в регистрах `__m512`.
