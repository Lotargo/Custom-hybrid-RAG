# Инструкции для AI Агентов (Jules)

Этот проект — высокопроизводительная система на C++23. Каждое решение должно быть обоснованным, архитектурно чистым и проверенным.

## 1. Кодекс работы агента (Core Rules)

1.  **Следование планам:** Все действия должны строго опираться на [roadmap.md](file:///f:/lock-rep-stable-projects/Custom-RAG/roadmap.md) и [patterns.md](file:///f:/lock-rep-stable-projects/Custom-RAG/patterns.md).
2.  **Дисциплина прогресса:** После завершения любой задачи агент ОБЯЗАН вычеркнуть (отметить как выполненную) соответствующий пункт в `roadmap.md` и/или в «Архитектурной карте реализации» файла `patterns.md`.
3.  **Запрет на заглушки (No Stubs):** Категорически запрещено оставлять пустые функции, выбрасывать `std::runtime_error("Not implemented")` или писать "TODO" вместо реальной логики. Весь код должен быть рабочим и законченным.
4.  **Нулевой технический долг:** Запрещено оставлять архитектурные костыли "на потом". При обнаружении несоответствия между новой задачей и старым кодом — сначала проведите рефакторинг, а затем реализацию. 
5.  **Максимальная производительность:** Ваш код будет работать с данными в сотни гигабайт. Избегайте лишних аллокаций, копирований и используйте современные C++ концепции (`std::span`, `mmap`, `SIMD`).
6.  **Принцип проверяемости (Verifiability):** Каждый новый модуль должен сопровождаться бенчмарком, сравнивающим его производительность с базовой реализацией (например, SIMD vs Scalar или mmap vs ifstream). Если прирост производительности меньше ожидаемого — агент обязан предоставить краткий анализ причин (Cache misses, Branch misprediction и т.д.).

## 2. Тестирование и SIMD (AVX-512)

Хост-процессор песочницы может не поддерживать новые наборы инструкций (например, AVX-512), из-за чего тесты и бенчмарки могут "скипаться", а реальная проверка кода будет невозможна.

**Для полноценного тестирования AVX-512 (или других новых архитектур) вам необходимо использовать Intel Software Development Emulator (Intel SDE).**

### Инструкция по установке Intel SDE в песочнице
Выполните следующие команды в bash для загрузки и распаковки актуального SDE:
```bash
mkdir -p /tmp/sde && cd /tmp/sde
wget -qO sde.tar.xz https://downloadmirror.intel.com/813591/sde-external-9.33.0-2024-01-07-lin.tar.xz
tar -xf sde.tar.xz --strip-components=1
```

### Как запускать тесты через эмулятор
После сборки проекта (`cmake .. && ninja`) запускайте бинарники через `sde64` с флагом `-skx` (Skylake-X perfil) или `-future`:
```bash
# Запуск юнит-тестов (AVX-512 тесты перестанут скипаться)
/tmp/sde/sde64 -skx -- ./build/tests/sonatadb_tests

# Запуск бенчмарков (для отладки падений, а не для замера времени)
/tmp/sde/sde64 -skx -- ./build/benchmarks/sonatadb_benchmarks
```

**Важное правило:** Никогда не предполагайте, что ваш AVX-512 код работает только потому, что он компилируется! Обязательно тестируйте его в Intel SDE.
